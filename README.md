# ✨ Key Features

## 🌿 Visual Design & Brand Identity

Designed a modern and intuitive organic e-commerce shopping experience with a strong focus on usability and customer engagement.

* Clean, responsive UI optimized for desktop and mobile devices
* Fully detailed product pricing with transparent unit costs
* Dynamic discount system featuring:

  * **FRESH10** promotional coupon
  * **SUPERKART** premium discount coupon
* Interactive cart progress indicators
* Smooth shopping and checkout experience

## 🇮🇳 Indian Localization & Payment Integration

Built specifically for the Indian market with localized pricing and payment options.

### Supported Payments

* NPCI Unified Payments Interface (UPI)
* Debit & Credit Card Payments

  * RuPay
  * Visa
  * Mastercard

### UPI Features

* Real-time UPI ID (VPA) validation
* Popular payment app selection grid

  * Google Pay
  * PhonePe
  * Paytm
  * BHIM
* Auto-generated SVG QR Code
* Live QR expiration countdown timer
* Secure and responsive checkout workflow

A comprehensive administration panel for monitoring business performance and managing operations.

### Dashboard Features

* Inventory and stock management
* Product CRUD operations
* Order management system
* Order status and milestone tracking
* Business performance overview
